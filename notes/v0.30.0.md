# v0.30.0 — 11 September 2026

## The office in one command

*install*

There was no way to get the office short of cloning it: the README opened with `npm start` for a reader who had nothing to start. `install.sh` existed and the address on the landing page pointed at `/dist/`, and `/dist/` pointed at nothing — a release on GitHub was notes and a tag, with no file a script could fetch.

Now `curl -fsSL https://valey.dev/install.sh | sh` puts the office into `~/valey` and says how to start it; `sh -s -- --run` starts it too, and `--pack=` folds a buyer's modules into the same command. The bytes come from the release page: every release carries the tarball of its tag and the checksum beside it, plus both under the name `latest`, and `valey.dev/dist/<version>/` is two redirect lines to those files. The script refuses an archive whose checksum does not match, and leaves nothing on disk when it does. What was left out on purpose: no `npm install`, because there is nothing to install, and no version lookup in the script — `latest` is resolved by GitHub, so the script stays short enough to read before running.
