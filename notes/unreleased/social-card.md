---
title: A shared link to the repository unfolds into a picture of the office
scope: share
---

A link to valey-core in a messenger unfolded into «Contribute to valey-dev/valey-core development by creating an account on GitHub» over GitHub's grey tile of zero stars and zero forks. The first thing a person saw of the project was an empty repository and a sentence about creating an account.

Now the repository has a description — «The pixel way to bring your Claude Code chats to life.» — and a 1280×640 card: the sign from the entrance, that line, and a slice of the floor with people at their desks. `node tools/social-card.mjs` makes it from the live canvas of a demo office, so every pixel is a whole square and the floor is invented: six made-up people on made-up projects. The office lights itself by the clock, so the script hands the browser a time zone where it is early afternoon, and the card is never cut at night.

Left out on purpose: GitHub has no API for the social preview, so the file is uploaded by hand in the repository settings. The same card is what valey.dev shows when its link is shared.
