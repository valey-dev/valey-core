---
title: A feature note can name the event the feature is meant to move
scope: tools
---

A release note says what a feature is, but not how anyone would know whether it is used — that lived nowhere, so it was never checked.

Now a note fragment may carry `event: Stick Moved`, the product event the feature is meant to move. The assembled note keeps it as a comment under the feature's heading — invisible on the release page, readable at the tag — so a tool that reads your own product analytics can put the feature and its numbers side by side. The office itself still collects nothing: the field names an event in your analytics, it does not send one.
